# 成王之路：元素远征

当前版本：**1.84**。单机横版动作 RPG 原型。选择战士或法师，在新手试炼后踏上十片遗迹的远征，清理守卫、击败守关者，并在小镇整备装备、收集灵魂、研究天赋与抽奖。

## 启动

```sh
npm install
npm run dev
```

生产构建：`npm run build`。最多可保存 3 个独立角色档案，自动写入当前浏览器的 `localStorage`。新建角色不会覆盖已有档案；档位已满时需选中目标档并确认后才会覆盖。标题页可逐档删除，删除前会再次确认。标题页以场景画作为全屏背景，存档与职业选择面板居中显示并保留半透明效果，背景画面会从面板后方透出。

体验版构建（**不会影响正式版**）：

```sh
npm run build:demo
npm run preview:demo
```

体验版输出到 `dist-demo/`，使用独立的浏览器存档键，解锁全部关卡；除当前关卡外其余关卡标记为已通关，可直接选择任意关卡或直接挑战任意 Boss。当前关卡保留真实进度，便于体验继续/重开。体验版只允许通过 `localhost` / `127.0.0.1`（或本地文件）打开；如果被部署到公网域名，会显示“体验版仅限本地使用”的锁定页。正式构建 `npm run build` 与 GitHub Pages 部署仍只读取 `dist/`，正式版行为不变。

## 账号与云存档

游戏支持 Bmob 云端账号，打开网页后先登录或注册。

- 注册：用户名 + 邮箱 + 密码（Bmob 要求填写邮箱）
- 登录：用户名 + 密码
- 忘记密码：使用注册邮箱重置
- 登录后存档自动同步到云端，换手机或电脑登录同一账号可继续进度
- 离线试玩：不登录也能玩，进度只保存在当前设备
- 每个账号最多 3 个存档槽

开发者配置：请在 Bmob 控制台把 `GameProfile` 数据表的权限设置为“仅创建者可读写”。`src/cloud.ts` 中只放客户端的 Secret Key 和 API 安全码，绝对不要放 Master Key。

## 操作

- `A / D` 或方向键：移动
- `J`：普通攻击
- 连击：命中敌人累计连击，5 秒内没有命中或被击中 2 次后清零。连击达到 50 / 150 / 300 时分别获得 2% / 5% / 10% 攻击加成；连击数字会比旧版大一倍，并随连击数继续变大、改变颜色和光效
- `K`：跳跃；在空中再按一次 `K` 进行二段跳
- `1 / 2 / 3 / 4`：释放技能
- `P`：暂停或继续
- 剧情对话：`Enter` / 空格 / 攻击键（默认 `J`）继续
- `S`：靠近掉落的血瓶/蓝瓶时拾取并立即使用（恢复最大生命/法力的 17.5%）；在小镇走到商人面前按 `S` 打开商城/天赋菜单
- `L`（按住）：在武器前方生成护盾；护盾改为按当前生命比例减伤，血量越低减伤越高（约 15%–60%），生命低于 10% 时完全免疫伤害。护盾持续期间每秒消耗 3 点法力，并暂停法力自动回复，松开 `L` 解除
- 音效与背景音乐：在“设置”中开关；首次点击页面或按键后才会开始播放
- 小镇内可以用 `A / D` 走动，也可以跳跃、攻击和释放技能；镇内练习不消耗法力，技能耗蓝只在关卡内生效
- 游戏画面右上角的“功能”菜单提供背包、技能、属性分配、抽奖与隐藏关卡入口；合成台在画面左下角与背包并排，通关第一关后解锁
- 商人阿岩和远征法阵只能在画面中走近后按 `S` 互动，不再出现在功能菜单里；功能菜单不显示背包，背包使用左下角独立按钮；集齐 10 枚王印印章后功能菜单才会显示隐藏关卡入口
- 游戏画面右上角的“设置”提供角色选择、返回小镇、退出游戏与按键设置；打开设置或功能菜单时游戏会暂停
- 手机端竖屏：左右移动键、攻击、跳跃、`S`、`L` 和技能键全部**覆盖在战斗画面内部**，按键背景进一步降低不透明度。左右移动键已放大到原来的约两倍；左下角的背包与技能按钮在手机端缩小到原来的约四分之一。摇杆整体右移，右侧技能与动作键整体左移。右下方最下排左攻击、右跳跃，中间左 `S`（拾取/对话）、右 `L`（按住护盾），上方技能键从左到右为 **3、4、1、2**。横屏时同样覆盖在战斗画面左右两侧。每个触控点独立记录，可以一边按住左右移动、一边攻击或跳跃；长按按钮不会触发浏览器的文本选择或长按菜单；桌面端保持原尺寸与键盘操作，技能介绍可在背包“技能”页查看
- 战斗画面左上角显示角色头像、等级、生命、法力和经验；顶部中央显示当前区域与击杀进度；命中数字显示在目标上方，每只敌人有独立头顶血条

## 手机横屏

- 进入游戏后界面会铺满整个浏览器窗口，不再显示网页头部、侧栏、底部技能说明或血条区域。
- 战斗画面会按屏幕比例补足上方天空与下方地面：桌面端和横屏基本保持原始比例，手机竖屏会把游戏世界居中显示，避免角色被拉伸。
- 右上角“功能”菜单集中了背包、技能、属性、抽奖和隐藏关卡；合成台与背包并排放在左下角，商人阿岩与远征法阵需要在画面中走近按 `S` 互动。
- 游戏画面按设备像素密度进行高清渲染（最高 2.5 倍分辨率），文字与模型边缘更加清晰。
- “设置 · 按键设置”可以重新绑定移动、攻击、跳跃和技能 1–4；点击项目后按下新按键即可，设置会保存在当前浏览器。方向键移动、`S` 拾取/对话、`L` 护盾和 `P` 暂停为固定按键。
- 竖屏时也可以完整游玩；旋转手机后布局会自动切换为横屏全屏。
- 添加到手机主屏幕后，Android 会按 manifest 以横屏模式启动。

## 新手试炼

新角色第一次进入游戏时，会先进入独立的新手试炼场：

- 训练傀儡拥有 1000 生命，不会主动攻击。
- 依次完成移动、攻击、二段跳、释放技能 4 个引导目标后，训练傀儡才会开始受到伤害。
- 击败训练傀儡后显示“新手指引完成”，随后进入冒险者小镇，并依次介绍背包、属性分配、合成台、商人和抽奖。
- 已经存在的老存档会自动视为完成新手引导。

## 剧情

十关主线围绕“王印”与“锁”展开，反派灰冠试图集齐十印打开王座下的封印。剧情会在每关开始前播放，并随关卡推进发生变化：

- 第 3、5、7 关会分别救出阿岩、小满、老周，救下的同伴会改变第 9 关的剧情。
- 阿岩就是小镇营火集市里的商人；第 5 关救出的小满与第 7 关救出的老周会回到小镇，头顶显示名字，走近后按 `S` 可以听他们说“谢谢”。
- 第 8 关需要做出选择：**先救宿敌**、**先追灰冠**；如果已经救过阿岩、小满和老周，还可以选择**一起净化**。
- 第 8 关的选择决定宿敌与主角的关系，并影响第 10 关结局和隐藏关卡的性质。
- 第 10 关击败锁灵后会进入终章剧情，随后开启隐藏关卡。
- 每段剧情只播放一次，已经看过的剧情不会重复出现。

## 隐藏关卡

- 每次击败 Boss 有 **40%** 概率获得 1 枚王印印章，结算界面会显示当前印章数量与 `10` 枚的解锁进度。
- 集齐 10 枚王印印章后，小镇右侧会出现“挑战宿敌”入口。
- 宿敌是创建角色时没有选择的另一个职业，会使用该职业的完整技能组；拥有 99,000 生命、2,900 攻击和 1,000 法力。
- 宿敌会在战斗中途更换武器：头顶出现金色武器轮廓并提示“更换武器”，2.5 秒前摇期间站立不动、浑身冒金光，受到的伤害增加 10%；换装完成后职业与技能组随之更换。宿敌同样视为 Boss，号角的装备掉率增益对宿敌按 Boss 的 +10% 结算。
- 隐藏关卡中玩家不会获得生命回复，法力仍会正常回复，也没有眩晕效果。
- 胜利后根据第 8 关的选择播放交好或决裂结局。隐藏关卡可以重复挑战，不影响主线进度。

## 属性点

- 每击杀 10 只小怪获得属性点：第 N 关每次获得 N 点。
- 每个关卡最多获得 20 点属性点。第 1~6 关分别为 3 / 6 / 9 / 12 / 15 / 18 点，第 7~10 关各 20 点。
- 1 点属性点可分配为：生命 +10、攻击 +1、法力 +1、防御 +1。
- 在小镇的“属性”面板中分配，加点和减点都会立即生效并自动保存；长按 `+` / `−` 可以连续调整，按住越久速度越快。每个关卡的点数只计算一次，重新挑战不会重复超过上限。

背景音乐改为更有推进感的合成纯音乐：战斗与 Boss 曲加入鼓点、低音与琶音层，整体音量提高；所有音效同步增强。跳跃高度不再设上限，从高处平台起跳会继续上升，不会在画面上方被卡住。

角色与普通小怪模型缩小到原来的 0.8 倍，Boss 仍保持原有巨大体型，战斗视野因此更加开阔。手机端的长按操作按钮已禁用浏览器文本选择和长按菜单。

页面缩放或窗口变化时，战斗区内的敌人血条、字号和背景会按比例缩放；浏览器缩放也会整体放大小镇和战斗界面。

## 关卡与敌人

每关需要击败 50 只小怪，再迎战 Boss。小怪按每波 5 只出现，并且会同时从角色左右两侧生成；清空一波后地图会向右解锁新的区域，继续向右走，到达新的触发点后才会刷新下一波。清完最后一波后继续向右前进，进入 Boss 领域。地图会随波次不断延伸，摄像机跟随角色，小怪和 Boss 都被限制在当前已解锁区域内。每只敌人有独立头顶血条；命中会显示并淡出伤害数字。每个关卡都有独立的天空、山体、地面和场景装饰，向右解锁的新区域会切换成不同的远景。

所有战斗场景都加入了可以站立的树枝、岩石、遗迹平台和水晶台；跳上平台后可以停下攻击，也可以从平台边缘走落。平台与场景装饰会随关卡主题变化。

第 4 关起部分小怪会飞行，悬浮在更高的空中并沿上下起伏的轨迹移动和攻击；可以用普通攻击、技能或二段跳应对。人物、小怪和 Boss 都有移动摆动与攻击前冲动画，普通攻击和 Boss 技能带有对应的打击特效。

角色攻击特效会随当前武器变化：长剑、战斧、法杖、守誓之刃、长弓、魔法书分别使用不同的弧光、箭矢、闪电、书页光效、颜色和粒子；武器等级越高，特效颜色也会继续变化。跳跃攻击时，攻击特效会跟随角色在空中、出现在武器前方。受击特效会随当前护甲的名称和等级改变颜色与光环样式。时装会在角色周围生成环绕光点，阶级越高，轨道与粒子越丰富。

战士拔剑术会挥出多层剑气；螺旋斩会带着剑气与怪物盘旋升空；拔剑突刺会先拔剑再突进、结束后收剑；万剑归宗会降下十余把交叉巨剑同时插入地面，产生连续爆炸、裂纹与屏幕震动。

Boss 冲刺伤害为 Boss 攻击力的 150%。小怪与 Boss 的普通攻击减去玩家防御后生效，最低造成 3 点伤害。

第 4 关起 Boss 会使用远程攻击，并且关卡越靠后攻势越强：

击败 Boss 后会先播放约 2.8 秒的胜利演出：金色冲击波、旋转光芒、`BOSS DEFEATED` 标题与“守关者宝箱已出现”提示。演出结束后不会立刻返回小镇，而是在 Boss 倒下的位置留下一个实体宝箱；走到宝箱旁按 `S` 会播放开箱动画，打开后弹出本次掉落清单，点击“收下奖励”才会进入下一关的小镇准备阶段或通关结局。下一关必须从第一波开始，不能直接挑战 Boss。

## 装备

装备分为武器、护甲和时装：武器增加蓝量与攻击，护甲增加生命与防御，时装提供百分比与固定属性加成；只有穿戴后生效。角色模型会随当前武器、护甲等级和时装阶级改变配色与装饰。

武器分为 4 个战斗类别：

| 类别 | 可用职业 | 说明 |
| --- | --- | --- |
| 剑类（剑 / 斧 / 刃） | 战士 | 基础近战武器，攻击为全额 |
| 弓箭 | 战士 | 同等级攻击为剑类的 90%；远程普通攻击，不穿透 |
| 法杖 | 法师 | 基础法系武器，攻击为全额；普通攻击为横向闪电 |
| 魔法书 | 法师 | 同等级攻击为剑类的 90%；普通攻击为可穿透的魔法弹，射程约半个画面 |

只有对应职业可以穿戴武器；背包中会标记“职业不符”。第 N 级武器/护甲的属性为（弓箭/魔法书按上表折扣后生效）：

```text
护甲：生命 +100 × (1 + N(N-1)/2)，防御 +10 + 5 × N(N-1)/2
武器：攻击 +10 + 5 × N(N-1)/2，蓝量 +10 + 30 × (N-1)
```

| 等级 | 护甲生命 | 护甲防御 | 武器攻击 | 武器蓝量 |
| ---: | ---: | ---: | ---: | ---: |
| 1 | 100 | 10 | 10 | 10 |
| 2 | 200 | 15 | 15 | 40 |
| 3 | 400 | 25 | 25 | 70 |
| 4 | 700 | 40 | 40 | 100 |
| 5 | 1100 | 60 | 60 | 130 |

法师的护甲生命/防御与武器蓝量仍为上述数值的 80%（取整）；武器攻击不再按职业打折，法杖与剑相同，魔法书与弓为剑类的 90%。小镇合成台分为左右两栏：左侧是合成孔位（武器/护甲 5 个，时装 3 个），右侧列出背包中未穿戴的装备，点击“放入”把材料放进孔位，点击已放入的孔位可以取出。集齐 5 件同类同级武器/护甲，或 3 件同阶时装后点击“合成”即可获得高一级装备/下一阶时装；每次装备合成消耗 **1000 灵魂**。合成品不会自动穿戴，装备等级与时装阶级均无上限。合成台顶部提供“装备合成 / 专属合成 / 强化石”分类，宝石与打孔入口将在后续版本开放。

## 专属材料与专属合成

每关小怪有 3 种专属掉落物（名字各不相同），每种独立判定：

- 第 1~4 关：每种 20% 概率掉落。
- 第 5~6 关：每种 15% 概率掉落。
- 第 7~10 关：每种 10% 概率掉落。
- 掉落后会以实体模型留在战场上，靠近按 `S` 拾取，不会直接进入背包。

合成台的“专属合成”页可以放入 3 个专属材料，材料可以来自不同关卡，按其中最高关卡结算：

| 最高关卡 N | 产物 | 灵魂消耗 |
| ---: | --- | ---: |
| 奇数 N | 1 件 `ceil(N/2)` 级装备 | `N × 1000` |
| 偶数 N | 1 件 `N/2` 级装备 + 1 件 `max(1, N/2-1)` 级装备 | `N × 1000` |

例如：第 1 关材料 → 1 件 1 级装备；第 2 关 → 2 件 1 级装备；第 3 关 → 1 件 2 级装备；第 4 关 → 1 件 2 级 + 1 件 1 级装备；第 5 关 → 1 件 3 级装备，以此类推。产物随机为武器或护甲。

## 强化石与装备强化

强化石分为 1~5 阶，主要通过噩梦 Boss 获得。合成台的“强化石”页可以用 **4 个同阶强化石合成 1 个高一阶强化石**。

通关第 5 关后，小镇左侧会出现第二位 NPC **铸魂师·霍恩**，靠近按 `S` 可以打开副本挑战和装备强化：

- 强化的是**装备槽位**（主武器槽、护甲槽，解锁双持后还有副武器槽），不是某一件具体装备；更换装备后强化等级保留。
- 武器槽每级：攻击 +2% × 强化等级，蓝量按 5% / 7% / 9%… 递增。
- 护甲槽每级：生命 +2% × 强化等级，防御按 5% / 7% / 9%… 递增。
- 一阶强化石的基础成功率：+0→+1 100%，之后 90 / 80 / 70 / 60 / 50 / 40 / 30 / 20%，再往后每次 -5% 直到 1% 后保持 1%。
- 二阶强化石在一阶基础上 +20%，三阶 +40%，四阶 +60%，五阶 +80%（上限 100%）。
- 强化失败会消耗强化石，但下一次成功率 +5%；成功后该加成重置。

## 噩梦副本

铸魂师·霍恩的“副本挑战”可以直接挑战十个普通关卡的噩梦 Boss：

- 副本按顺序解锁：必须先通关对应普通关卡，并通关上一关的噩梦 Boss，才能挑战下一关噩梦 Boss。第 1 关噩梦只需要通关普通第 1 关。
- 噩梦 Boss 生命为普通 Boss 的 **2 倍**，攻击为 **1.5 倍**。
- 噩梦 Boss 只掉落强化石。设关卡为 N：
  - N % 3 = 1：掉落 1 个 `ceil(N/3)` 阶强化石；首通 2 个。第 1、4、7、10 关对应 1、2、3、4 阶。
  - N % 3 = 2：掉落 2 个 `ceil(N/3)` 阶强化石；首通 3 个。第 2、5、8 关对应 1、2、3 阶。
  - N % 3 = 0：66.6% 掉落 3 个 `N/3` 阶强化石，33.3% 掉落 1 个 `N/3+1` 阶强化石；首通固定 1 个 `N/3+1` 阶强化石。第 3 关：3 个一阶或 1 个二阶，首通 1 个二阶；第 6、9 关以此类推。
  - 首通奖励按每个关卡单独记录。

小怪有 5% 概率掉落武器、5% 概率掉落护甲（两者独立判定）；掉落品级从本关开始向下判定，本关级别的概率每级降低 1%，低级装备概率保持不变。Boss 的装备、灵魂、印章、抽奖机会和天赋币碎片不会再直接结算，而是全部放入战场的“守关者宝箱”，靠近按 `S` 开箱后获得。小怪另有 15% 概率掉落血瓶或蓝瓶，靠近后按 `S` 拾取并使用。

挑战失败时可以选择“继续战斗”“重新开始”或“回到小镇”：继续战斗会以最大生命的 50% 复活并保留当前波次进度；重新开始会恢复满生命/法力，并从本关第一波重新挑战；回到小镇会恢复满状态并返回安全区。已经通关过 Boss 的关卡，可以在小镇选择“重新开始”或“直接挑战 Boss”；未通关的关卡在小镇只能“重新开始（满状态）”，进入关卡一律从第一波开始，不再保留关卡内进度。进入小镇时生命与法力会自动回满。击败 Boss 并收下宝箱奖励后才会进入下一关的小镇准备阶段，新关卡必须从第一波开始。第十关 Boss 被击败后远征结束。

冒险者小镇是独立的安全地图，不会生成敌人，可以在限定范围内左右走动。进入小镇时生命与法力自动回满；游戏内右上角“功能”菜单提供属性分配、抽奖和隐藏关卡等功能，合成台在左下角与背包并排。小镇中央有一座发光的**远征法阵**：走到法阵内按 `S` 会打开关卡选择面板，可以直接选择任意已解锁的遗迹并从当前进度继续。商人阿岩站在法阵右侧，走到他面前按 `S` 打开商城与天赋菜单。从法阵进入任意关卡都会从第一波开始。最多保存 3 个角色档案，新角色优先创建在空档位；档位已满时必须选择目标档，并在系统确认提示中再次确认才会覆盖。

## 灵魂

灵魂是小镇商城的通用货币，每个存档独立累计：

- 击杀小怪：第 N 关获得 `N × 5` 灵魂。
- 击败 Boss：第 N 关获得 `N × 100` 灵魂。
- 灵魂可在商人处购买装备、天赋币碎片和时装，不会占用背包格位。

## 时装

时装只能从商城中购买、从抽奖中获得，或通过合成台合成；小怪和 Boss 都不会掉落。时装穿戴后提供以下加成：

| 阶级 | 生命 | 攻击 | 防御 | 蓝量 |
| ---: | --- | --- | --- | --- |
| 一阶 | +5% | +10 和 +5% | +10 和 +10% | +10 和 +5% |
| 二阶 | +10% | +20 和 +10% | +20 和 +15% | +20 和 +10% |
| 三阶 | +15% | +30 和 +15% | +30 和 +20% | +30 和 +15% |
| 四阶 | +20% | +40 和 +20% | +40 和 +25% | +40 和 +20% |

更高阶级按同样规律继续增长：每阶生命/攻击/蓝量百分比 +5%，固定值 +10；防御百分比从 10% 起每阶 +5%。百分比按角色当前对应属性计算。

合成台可用 **3 件未穿戴的同阶时装** 合成 1 件下一阶时装，二阶可由三件一阶合成，三阶、四阶以此类推，阶级无上限。穿戴时装后，角色披风、轮廓光和金色饰边会随阶级改变颜色。

## 天赋

角色达到 **5 级**后解锁天赋功能，在小镇商人处研究。

**普通天赋**可以全部同时激活并分别升级，不再限制只能选一个：

- 激活消耗 1 个天赋币；升级费用依次为 1、2、3、4… 个天赋币。
- 可以撤销一级并返还该级投入的天赋币，最低可撤销到未激活。
- 每级效果如下：

| 天赋 | 每级效果 | Lv.1 / Lv.2 / Lv.3 |
| --- | --- | --- |
| 生命祝福 | 生命上限 +2% | +2% / +4% / +6% |
| 锋锐 | 攻击力 +2% | +2% / +4% / +6% |
| 守护 | 防御力 +5% | +5% / +10% / +15% |
| 灵泉 | 法力上限 +2% | +2% / +4% / +6% |

普通天赋没有等级上限。

**高级天赋**只能激活一个，但可以继续升级：

- 激活消耗 3 个天赋币；升级费用依次为 3、5、7、9… 个天赋币。
- 撤销一级会返还该级费用；重置会返还该高级天赋的全部投入，之后可重新选择。

| 天赋 | Lv.1 效果 | 升级规律 |
| --- | --- | --- |
| 奥术精通 | 法力上限 +5%，技能伤害 +10% | 每级法力上限 +2%、技能伤害 +2%（Lv.2：7% / 12%） |
| 生命转换 | 生命上限的 1% 转化为法力上限 | 每级额外 +0.5%（Lv.2：1.5%）；生命上限不会减少 |
| 双持专精 | 可以额外装备一把武器**或**一件护甲（二选一） | 从 Lv.2 起，每级提高装备属性 2%（Lv.2：+2%，Lv.3：+4%） |

额外武器只提供攻击与蓝量属性，不会改变技能组；主手武器决定普通攻击与技能。剑与弓同时装备时，可以通过背包中的“主手 / 副手”选择哪一把作为攻击武器。

天赋币碎片来源：

- 第 3 关起，Boss 有概率掉落 1 个天赋币碎片；第 3 关概率 20%，第 4 关 25%，第 5 关 30%，之后每关 +5%，第 10 关为 55%。
- 集齐 10 个碎片后，可在天赋面板中消耗 **500 灵魂** 合成 1 个天赋币。
- 天赋币碎片不再转化为灵魂，会一直保留用于合成天赋币。

号角：购买后存放在背包的“其他”页，点击“使用”会打开增益选择面板，可选**关卡材料掉率翻倍**、**攻击力 +10%**、**装备掉率 +20%（对 Boss 只提高 10%，隐藏关卡的宿敌也按 Boss 结算）**。选择后播放 2 秒全屏吹号动画，增益持续 30 分钟；生效期间战斗左上角角色头像下方会显示号角图标、增益名称和剩余时间。重复使用号角会覆盖当前号角增益。

复活币：在战斗中被击败时，如果背包里有复活币且本关还没有使用过，可以在失败界面选择“使用复活币（满状态）”，立即以满生命/满法力复活并保留当前进度。每个关卡只能使用一次，重新进入关卡后才会重置。

背包分为“装备 / 天赋币 / 其他 / 技能”四个分类，每个物品都有独立图标。背包左下角的快捷按钮或“功能”菜单都可以打开背包；背包内可查看生命、法力、攻击、防御、等级和已穿戴的武器、副手、护甲、时装，左侧新增角色全身预览，更换装备后会立即显示新装备的外观。双持专精选择“额外武器”时，背包会为每把武器提供“主手 / 副手”两个装备位置；选择“额外护甲”时，护甲会提供“主护甲 / 副护甲”两个位置。“技能”页会显示当前主手武器对应技能组的完整介绍、伤害、法力消耗和当前按键。
