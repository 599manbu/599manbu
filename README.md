# 冒险王：元素远征

当前版本：**1.40**。单机横版动作 RPG 原型。选择战士或法师，在十片遗迹中清理守卫、击败守关者，并在小镇整备装备。

## 启动

```sh
npm install
npm run dev
```

生产构建：`npm run build`。最多可保存 3 个独立角色档案，自动写入当前浏览器的 `localStorage`。新建角色不会覆盖已有档案；档位已满时需选中目标档并确认后才会覆盖。标题页可逐档删除，删除前会再次确认。

## 操作

- `A / D` 或方向键：移动
- `J`：普通攻击
- `Space` 或 `↑`：跳跃
- `1 / 2 / 3 / 4`：释放技能
- `P`：暂停或继续
- `S`：靠近掉落的血瓶/蓝瓶时拾取并立即使用
- 小镇“合成台”：独立打开合成界面；背包仅用于查看和穿戴装备。5 件未穿戴的同类同级装备可合成高一级装备。
- 游戏顶栏的“角色选择”：自动保存后返回存档与职业选择页
- 移动端可使用屏幕上的左右移动按钮
- 命中数字显示在目标上方；每只敌人有独立头顶血条，玩家生命/法力条位于战斗区下方

## 职业与技能

两种职业的基础属性均为生命 1000、法力 500、攻击 10、防御 10。法力每秒回复 4 点。
角色经验门槛依次为 200、500、1200、2700，之后每级翻倍。每次升级增加生命/防御 100、200、400、800……，攻击/蓝量增加 10、20、40、80……。

| 按键 | 战士 | 法师 | 基础伤害 | 消耗 |
| --- | --- | --- | ---: | ---: |
| 1 | 前斩 | 奥术强化，5 秒内强化法杖攻击 | 20 | 10 MP |
| 2 | 旋风斩 | 向前升起双生火柱 | 30 | 20 MP |
| 3 | 突刺 | 向前闪现 | 40 | 30 MP |
| 4 | 蓄力重斩 | 能量阵释放 8 次攻击 | 50 | 40 MP |

技能带有短暂冷却。防御力会抵消敌方攻击伤害；普通攻击造成基础攻击力的 2.4 倍伤害。
技能冷却依次为 0.65、0.9、1.15、1.5 秒。战士突刺会伤害整段突进路径上的敌人。每个 Boss 根据关卡使用不同主题的蓄力、冲刺和近身攻击特效。

## 关卡与装备

每关先挑战 30 只小怪，再迎战 Boss。小怪从左右两侧分批出现，每批 2 至 3 只，每只敌人有独立头顶血条；命中会显示并淡出伤害数字。第一关小怪生命为 100、Boss 生命为 2000，后续每关翻倍。小怪有 5% 概率、Boss 有 20% 概率掉落装备。角色生命/法力显示在战斗区域下方，小镇没有敌人，可免费恢复并选择任一已解锁关卡。

装备分为武器和护甲：武器增加蓝量与攻击，护甲增加生命与防御。第 N 级护甲属性为 `100 × 2^(N-1)`，武器属性为 `10 × 2^(N-1)`；只有穿戴后生效。小镇合成台可用 5 件未穿戴的同类同级装备合成高一级装备，合成品不会自动穿戴，等级无上限。

小怪掉落装备时，品级从本关开始向下判定：本关级别的概率每级降低 1%，低级装备概率保持不变；Boss 有 70% 概率掉落一件本关装备。小怪另有 25% 概率掉落血瓶或蓝瓶，靠近后按 `S` 拾取并使用。怪物与 Boss 伤害随关卡递增。击杀进度按关卡分别保存；回镇后可继续该关，倒在 Boss 战后可以直接挑战 Boss。Boss 已击败的关卡可选择从第一波重开或直接重战 Boss。第十关 Boss 被击败后远征结束。

冒险者小镇是安全区，不会生成敌人；可以免费恢复生命/法力、打开背包及进入任一已解锁关卡。最多保存 3 个角色档案，新角色优先创建在空档位；档位已满时必须选择目标档，并在系统确认提示中再次确认才会覆盖。
