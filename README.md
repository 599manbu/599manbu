# 冒险王：元素远征

当前版本：**1.67**。单机横版动作 RPG 原型。选择战士或法师，在新手试炼后踏上十片遗迹的远征，清理守卫、击败守关者，并在小镇整备装备、收集灵魂、研究天赋与抽奖。

## 启动

```sh
npm install
npm run dev
```

生产构建：`npm run build`。最多可保存 3 个独立角色档案，自动写入当前浏览器的 `localStorage`。新建角色不会覆盖已有档案；档位已满时需选中目标档并确认后才会覆盖。标题页可逐档删除，删除前会再次确认。

体验版构建（**不会影响正式版**）：

```sh
npm run build:demo
npm run preview:demo
```

体验版输出到 `dist-demo/`，使用独立的浏览器存档键，解锁全部关卡；除当前关卡外其余关卡标记为已通关，可直接选择任意关卡或直接挑战任意 Boss。当前关卡保留真实进度，便于体验继续/重开。体验版只允许通过 `localhost` / `127.0.0.1`（或本地文件）打开；如果被部署到公网域名，会显示“体验版仅限本地使用”的锁定页。正式构建 `npm run build` 与 GitHub Pages 部署仍只读取 `dist/`，正式版行为不变。

## 账号与云存档

游戏支持 Bmob 云端账号，打开网页后先登录或注册。

- 注册：用户名 + 邮箱 + 密码（Bmob 要求填写邮箱）
- 登录：用户名 + 密码
- 忘记密码：使用注册邮箱重置
- 登录后存档自动同步到云端，换手机或电脑登录同一账号可继续进度
- 离线试玩：不登录也能玩，进度只保存在当前设备
- 每个账号最多 3 个存档槽

开发者配置：请在 Bmob 控制台把 `GameProfile` 数据表的权限设置为“仅创建者可读写”。`src/cloud.ts` 中只放客户端的 Secret Key 和 API 安全码，绝对不要放 Master Key。

## 操作

- `A / D` 或方向键：移动
- `J`：普通攻击
- `K`：跳跃；在空中再按一次 `K` 进行二段跳
- `1 / 2 / 3 / 4`：释放技能
- `P`：暂停或继续
- `S`：靠近掉落的血瓶/蓝瓶时拾取并立即使用；在小镇走到商人面前按 `S` 打开商城/天赋菜单
- `L`（按住）：在武器前方生成护盾，防御力 ×10；护盾持续期间每秒消耗 3 点法力，并暂停法力自动回复，松开 `L` 解除
- 顶部 `♪`：音效与背景音乐开关；首次点击页面或按键后才会开始播放
- 小镇内可以用 `A / D` 走动，也可以跳跃、攻击和释放技能；镇内练习不消耗法力，技能耗蓝只在关卡内生效
- 小镇右侧面板提供合成台、属性分配、抽奖和关卡选择；通关第一关后解锁合成台与商人，集齐 10 枚王印印章后出现隐藏关卡入口
- 小镇“属性”：打开属性分配面板；可用属性点来自击杀小怪
- 小镇“合成台”：通关第一关后解锁，独立打开合成界面；背包仅用于查看和穿戴装备。5 件未穿戴的同类同级装备可合成高一级装备
- 游戏顶栏的“角色选择”：自动保存后返回存档与职业选择页
- 手机端竖屏：左右移动键、攻击、跳跃、`S`、`L` 和技能键全部**覆盖在战斗画面内部**，不再占用地图下方的页面空间。左下方为横向排列的左右移动键；右下方最下排左攻击、右跳跃，中间左 `S`（拾取/对话）、右 `L`（按住护盾），上方技能键从左到右为 **3、4、1、2**。横屏时同样覆盖在战斗画面左右两侧。所有按键已放大并带半透明背景；每个触控点独立记录，可以一边按住左右移动、一边攻击或跳跃；长按按钮不会触发浏览器的文本选择或长按菜单；桌面端保持原布局
- 命中数字显示在目标上方；每只敌人有独立头顶血条，玩家生命/法力条位于战斗区下方

## 手机横屏

- 游戏页顶部的“横屏”按钮会尝试进入全屏并锁定横屏。Android Chrome 支持自动锁定；iPhone Safari 不支持自动锁定，请手动把手机横过来并关闭竖屏锁定。
- 竖屏打开时会显示“横屏体验更好”的提示，可以点击“进入横屏”，也可以关闭提示继续竖屏游玩。
- 横向布局会隐藏侧栏和关卡概览，保留战斗区、生命/法力条，以及战斗区左右两侧的移动、技能 1–4、攻击/跳跃按钮。
- 添加到手机主屏幕后，Android 会按 manifest 以横屏模式启动。

## 新手试炼

新角色第一次进入游戏时，会先进入独立的新手试炼场：

- 训练傀儡拥有 1000 生命，不会主动攻击。
- 依次完成移动、攻击、二段跳、释放技能 4 个引导目标后，训练傀儡才会开始受到伤害。
- 击败训练傀儡后显示“新手指引完成”，随后进入冒险者小镇，并依次介绍背包、属性分配、合成台、商人和抽奖。
- 已经存在的老存档会自动视为完成新手引导。

## 剧情

十关主线围绕“王印”与“锁”展开，反派灰冠试图集齐十印打开王座下的封印。剧情会在每关开始前播放，并随关卡推进发生变化：

- 第 3、5、7 关会分别救出阿岩、小满、老周，救下的同伴会改变第 9 关的剧情。
- 阿岩就是小镇营火集市里的商人；第 5 关救出的小满与第 7 关救出的老周会回到小镇，头顶显示名字，走近后按 `S` 可以听他们说“谢谢”。
- 第 8 关需要做出选择：**先救宿敌**、**先追灰冠**；如果已经救过阿岩、小满和老周，还可以选择**一起净化**。
- 第 8 关的选择决定宿敌与主角的关系，并影响第 10 关结局和隐藏关卡的性质。
- 第 10 关击败锁灵后会进入终章剧情，随后开启隐藏关卡。
- 每段剧情只播放一次，已经看过的剧情不会重复出现。

## 隐藏关卡

- 每次击败 Boss 有 **40%** 概率获得 1 枚王印印章，结算界面会显示当前印章数量与 `10` 枚的解锁进度。
- 集齐 10 枚王印印章后，小镇右侧会出现“挑战宿敌”入口。
- 宿敌是创建角色时没有选择的另一个职业，会使用该职业的完整技能组；拥有 99,000 生命、2,900 攻击和 1,000 法力。
- 隐藏关卡中玩家不会获得生命回复，法力仍会正常回复，也没有眩晕效果。
- 胜利后根据第 8 关的选择播放交好或决裂结局。隐藏关卡可以重复挑战，不影响主线进度。

## 属性点

- 每击杀 10 只小怪获得属性点：第 N 关每次获得 N 点。
- 每个关卡最多获得 20 点属性点。第 1~6 关分别为 3 / 6 / 9 / 12 / 15 / 18 点，第 7~10 关各 20 点。
- 1 点属性点可分配为：生命 +10、攻击 +1、法力 +1、防御 +1。
- 在小镇的“属性”面板中分配，立即生效并自动保存；每个关卡的点数只计算一次，重新挑战不会重复超过上限。

## 视觉与敌人造型

每个关卡的小怪与 Boss 都有独立造型和配色：

- 苔痕边境：苔藓小妖 / 古木树王
- 沉钟矿道：寒晶爬虫 / 寒晶巨像
- 赤岩峡谷：熔岩蜥蜴 / 熔岩魔像
- 风蚀高原：风暴隼 / 雷翼巨禽
- 幽蓝沼泽：潮汐鳗 / 潮汐利维坦
- 断星回廊：虚空之眼 / 虚空巨眼
- 灰烬王庭：灰烬幽魂 / 灰烬巫王
- 深渊裂谷：血牙蛮兵 / 血牙暴君
- 苍白圣所：日轮祭司 / 日轮主教
- 终焉之门：星辰哨兵 / 星辰泰坦

战士模型重绘为带羽饰头盔、胸甲、披风、圆盾与长剑的样式；法师模型重绘为兜帽长袍、发光法杖与环绕符文的样式。1.66 进一步细化了双方模型：战士增加多层肩甲、发光面甲、剑格宝石、剑身符文与披风内衬；法师增加肩披、下摆符文、秘法冠环、法杖光环与环绕棱晶。所有敌人与 Boss 增加主题色轮廓光，Boss 周身会浮现能量碎晶。敌人头顶血条会贴合各自模型的高度显示。

背景音乐改为更有推进感的合成纯音乐：战斗与 Boss 曲加入鼓点、低音与琶音层，整体音量提高；所有音效同步增强。跳跃高度不再设上限，从高处平台起跳会继续上升，不会在画面上方被卡住。

## 技能

普通攻击伤害为攻击力的 **100%**。技能伤害按总攻击力（基础 + 等级 + 装备 + 属性点）的百分比计算。

**战士**

| 按键 | 技能 | 伤害 | 消耗 |
| --- | --- | ---: | ---: |
| 1 | 前斩 | 150% 攻击 | 20 MP |
| 2 | 旋风斩 | 150% 攻击（范围内全部敌人） | 30 MP |
| 3 | 突刺 | 100% 攻击（整段突进路径） | 20 MP |
| 4 | 蓄力重斩 | 200% 攻击（范围内全部敌人） | 50 MP |

**法师**

| 按键 | 技能 | 效果 | 消耗 |
| --- | --- | --- | ---: |
| 1 | 奥术强化 | 攻击 +10%、攻速 +10%，持续 7 秒 | 40 MP |
| 2 | 双生火柱 | 在固定前方距离生成火柱，造成 160% 攻击，并把范围内非 Boss 敌人强力拉向火柱中间 | 30 MP |
| 3 | 闪现 | 无伤害，瞬间向前移动 | 10 MP |
| 4 | 能量禁锢 | 控制目标 1 秒，并瞬发 5 次带命中特效的普通攻击 | 50 MP |

所有技能均无冷却。技能 3（战士突刺 / 法师闪现）会按当前按下的方向键决定方向：按 `A + 3` 向左，按 `D + 3` 向右；没有按方向键时沿当前视角方向移动。没有敌人时也可以普通攻击，战士会挥出剑气，法师会向空地上发射光弹。战士前斩附带小幅击退；突刺会把路径上的非 Boss 敌人带到落点前方。法师双生火柱固定在当前朝向前方生成，并把范围内的非 Boss 敌人强力拉向两根火柱中间。法师施放奥术强化后，持续时间改为 7 秒，角色头顶会显示剩余时间的倒计时。防御力会抵消敌方攻击伤害。8 个技能各自拥有独立特效，重击、旋风斩与 Boss 技能带有屏幕震动反馈。每个 Boss 根据关卡使用不同主题的蓄力、冲刺和近身攻击特效。游戏包含攻击、技能、跳跃、角色/怪物受击等音效以及随场景变化的背景音乐。

角色与普通小怪模型缩小到原来的 0.8 倍，Boss 仍保持原有巨大体型，战斗视野因此更加开阔。手机端的长按操作按钮已禁用浏览器文本选择和长按菜单。

页面缩放或窗口变化时，战斗区内的敌人血条、字号和背景会按比例缩放；浏览器缩放也会整体放大小镇和战斗界面。

## 关卡与敌人

每关需要击败 50 只小怪，再迎战 Boss。小怪按每波 5 只出现，并且会同时从角色左右两侧生成；清空一波后地图会向右解锁新的区域，继续向右走，到达新的触发点后才会刷新下一波。清完最后一波后继续向右前进，进入 Boss 领域。地图会随波次不断延伸，摄像机跟随角色，小怪和 Boss 都被限制在当前已解锁区域内。每只敌人有独立头顶血条；命中会显示并淡出伤害数字。每个关卡都有独立的天空、山体、地面和场景装饰，向右解锁的新区域会切换成不同的远景。

所有战斗场景都加入了可以站立的树枝、岩石、遗迹平台和水晶台；跳上平台后可以停下攻击，也可以从平台边缘走落。平台与场景装饰会随关卡主题变化。

第 4 关起部分小怪会飞行，悬浮在更高的空中并沿上下起伏的轨迹移动和攻击；可以用普通攻击、技能或二段跳应对。人物、小怪和 Boss 都有移动摆动与攻击前冲动画，普通攻击和 Boss 技能带有对应的打击特效。

角色攻击特效会随当前武器变化：长剑、战斧、法杖、守誓之刃分别使用不同的弧光、颜色和粒子；武器等级越高，特效颜色也会继续变化。跳跃攻击时，攻击特效会跟随角色在空中、出现在武器前方。受击特效会随当前护甲的名称和等级改变颜色与光环样式。时装会在角色周围生成环绕光点，阶级越高，轨道与粒子越丰富。

战士前斩会挥出更大的多层剑气、冲击波和更多粒子；蓄力重斩会生成巨型多层剑气、地面裂纹、飞石、冲天光柱与屏幕闪光，并伴随更强的屏幕震动。

## 装备

装备分为武器、护甲和时装：武器增加蓝量与攻击，护甲增加生命与防御，时装提供百分比与固定属性加成；只有穿戴后生效。角色模型会随当前武器、护甲等级和时装阶级改变配色与装饰。第 N 级武器/护甲的属性为：

```text
护甲：生命 +100 × (1 + N(N-1)/2)，防御 +10 + 5 × N(N-1)/2
武器：攻击 +10 + 5 × N(N-1)/2，蓝量 +10 + 30 × (N-1)
```

| 等级 | 护甲生命 | 护甲防御 | 武器攻击 | 武器蓝量 |
| ---: | ---: | ---: | ---: | ---: |
| 1 | 100 | 10 | 10 | 10 |
| 2 | 200 | 15 | 15 | 40 |
| 3 | 400 | 25 | 25 | 70 |
| 4 | 700 | 40 | 40 | 100 |
| 5 | 1100 | 60 | 60 | 130 |

法师的装备收益为上述数值的 80%（取整）。小镇合成台可用 5 件未穿戴的同类同级武器/护甲合成高一级装备，或用 3 件同阶时装合成下一阶时装；合成品不会自动穿戴，装备等级与时装阶级均无上限。

小怪有 5% 概率掉落武器、5% 概率掉落护甲（两者独立判定）；掉落品级从本关开始向下判定，本关级别的概率每级降低 1%，低级装备概率保持不变。Boss 有 70% 概率掉落一件本关装备。小怪另有 15% 概率掉落血瓶或蓝瓶，靠近后按 `S` 拾取并使用。

挑战失败时可以选择“继续战斗”“重新开始”或“回到小镇”：继续战斗会以最大生命的 50% 复活并保留当前波次进度；重新开始会恢复满生命/法力，并从本关第一波重新挑战；回到小镇会恢复满状态并返回安全区。已经通关过 Boss 的关卡，可以在小镇选择“重新开始”或“直接挑战 Boss”；未通关且已有进度的关卡，在小镇可以选择“继续战斗（半血）”或“重新开始（满状态）”。进入小镇时生命与法力会自动回满。击败 Boss 后会自动进入下一关的小镇准备阶段，新关卡必须从第一波开始。第十关 Boss 被击败后远征结束。

冒险者小镇是独立的安全地图，不会生成敌人，可以在限定范围内左右走动。进入小镇时生命与法力自动回满；小镇右侧面板提供合成台、属性分配、抽奖和关卡选择等功能。小镇中央新增一座发光的**远征法阵**：走到法阵内按 `S` 会打开关卡选择面板，可以直接选择任意已解锁的遗迹并从当前进度继续。已有未通关进度时，可以在小镇选择“继续战斗（半血）”或“重新开始（满状态）”。最多保存 3 个角色档案，新角色优先创建在空档位；档位已满时必须选择目标档，并在系统确认提示中再次确认才会覆盖。

## 灵魂

灵魂是小镇商城的通用货币，每个存档独立累计：

- 击杀小怪：第 N 关获得 `N × 5` 灵魂。
- 击败 Boss：第 N 关获得 `N × 100` 灵魂。
- 灵魂可在商人处购买装备、天赋币碎片和时装，不会占用背包格位。

## 时装

时装只能从商城中购买、从抽奖中获得，或通过合成台合成；小怪和 Boss 都不会掉落。时装穿戴后提供以下加成：

| 阶级 | 生命 | 攻击 | 防御 | 蓝量 |
| ---: | --- | --- | --- | --- |
| 一阶 | +5% | +10 和 +5% | +10 和 +10% | +10 和 +5% |
| 二阶 | +10% | +20 和 +10% | +20 和 +15% | +20 和 +10% |
| 三阶 | +15% | +30 和 +15% | +30 和 +20% | +30 和 +15% |
| 四阶 | +20% | +40 和 +20% | +40 和 +25% | +40 和 +20% |

更高阶级按同样规律继续增长：每阶生命/攻击/蓝量百分比 +5%，固定值 +10；防御百分比从 10% 起每阶 +5%。百分比按角色当前对应属性计算。

合成台可用 **3 件未穿戴的同阶时装** 合成 1 件下一阶时装，二阶可由三件一阶合成，三阶、四阶以此类推，阶级无上限。穿戴时装后，角色披风、轮廓光和金色饰边会随阶级改变颜色。

## 天赋

角色达到 **5 级**后解锁天赋功能，在小镇商人处研究。

**普通天赋**（首次选择消耗 1 个天赋币，之后更换免费；只能选择一个）：

| 天赋 | 效果 |
| --- | --- |
| 生命祝福 | 生命上限 +10% |
| 锋锐 | 攻击力 +10% |
| 守护 | 防御力 +20% |
| 灵泉 | 法力上限 +5% |

**高级天赋**（首次选择消耗 3 个天赋币，之后更换免费；只能选择一个）：

| 天赋 | 效果 |
| --- | --- |
| 奥术精通 | 法力上限 +5%，技能伤害 +10%，所有技能蓝耗 +5% |
| 生命转换 | 将生命上限的 1% 转化为法力上限 |
| 双持专精 | 可以额外装备一把武器，两把武器的攻击与蓝量叠加 |

天赋币碎片来源：

- 第 3 关起，Boss 有概率掉落 1 个天赋币碎片；第 3 关概率 20%，第 4 关 25%，第 5 关 30%，之后每关 +5%，第 10 关为 55%。
- 集齐 10 个碎片后，可在天赋面板中合成 1 个天赋币。
- 同时拥有普通天赋和高级天赋后，Boss 碎片掉落会转化为 **1000 灵魂**。

## 抽奖

- 首次通关每个关卡获得 1 次抽奖机会；重复通关已通关的关卡不会再次获得。
- 抽奖入口位于小镇右侧面板或商人菜单，抽奖动画约 3 秒。
- 第一次打开抽奖时会播放一次功能介绍；界面只展示奖励卡片，不显示概率。
- 奖池与概率（以下为规则文档，游戏内不展示）：

| 奖励 | 概率 |
| --- | ---: |
| 属性点 +10 | 20% |
| 当前品阶装备 ×2 | 10% |
| 天赋币 ×1 | 10% |
| 灵魂 ×2000 | 40% |
| 一阶时装 ×1 | 5% |
| 空奖 | 5% |
| 高一级装备 ×1 | 10% |

## 商城与背包

通关第一关后，小镇地图上会出现商人阿岩（也就是第 3 关救出的同伴）。第一次点击商人入口会播放一次功能介绍；之后走到他面前按 `S`，或点击小镇面板中的“阿岩 · 商人”，可打开商城、天赋和抽奖菜单。

| 商品 | 价格 | 说明 |
| --- | ---: | --- |
| 一阶护甲 ×1 | 1000 灵魂 | 随机 1 级护甲 |
| 一阶武器 ×1 | 1000 灵魂 | 随机 1 级武器 |
| 天赋币碎片 ×2 | 2000 灵魂 | 用于合成天赋币 |
| 一阶时装 ×1 | 10000 灵魂 | 限购一份 |

背包分为“装备 / 天赋币 / 其他”三个分类，每个物品都有独立图标。桌面端角色状态面板在打开背包时显示；背包内可查看生命、法力、攻击、防御、等级和已穿戴的武器、副手、护甲、时装。双持专精生效时，背包会为每把武器提供“主手 / 副手”两个装备位置。
